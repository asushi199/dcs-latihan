# Bilik Latihan DCS / DCS 闯关练习室

Latihan simulasi dwibahasa (Bahasa Cina dan Bahasa Melayu) sebanyak 20 peringkat untuk murid. Jenis soalan merujuk DCS; soalan ditulis semula dan markah tidak direkodkan.

**Laman:** https://asushi199.github.io/dcs-latihan/

## Cara guna

- Buka pautan di atas pada pelayar komputer, tablet atau telefon.
- Pautan terus ke peringkat tertentu: tambah `#level-5` (1 hingga 20) di hujung alamat.

## Struktur

- `index.html` — keseluruhan laman (HTML, CSS dan JavaScript dalam satu fail, tanpa proses binaan).

## Kemas kini

Sunting `index.html`, kemudian `git commit` dan `git push` ke cabang `main`. GitHub Pages akan menerbitkan semula secara automatik.
